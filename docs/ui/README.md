| Feature | Reference |

| Weight | [Dashboard and history](weight.md) |

Use this catalog to understand the current Jetpack Compose UI before proposing changes. For an affected screen, start from its source and the [Material 3 Design Kit](https://www.figma.com/community/file/1035203688168086460/material-3-design-kit). Review the proposed change in Figma before implementing it.

After visual review in Compose Preview or on an emulator, record the approved frame, implementation commit, relevant UI states, and representative screenshots. Use sample data and identify the viewport and theme. Link existing screenshot baselines from the catalog when they already capture the state.
